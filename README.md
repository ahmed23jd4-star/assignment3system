# Assignment 3 System

This project continues the pages from `assignment2system` and adds a JavaScript validated registration form and searchable, sortable data table.

## Pages

- `index.html`, `about.html`, `contact.html`, and `components.html` are the original project pages.
- `registration.html` checks name, email, password length, password confirmation, and age. Invalid submissions are prevented and each error appears under its field.
- `data.html` displays a JavaScript array of people, filters as you type, and sorts by name or age.

## Run

Open `index.html` in a browser. Use the navigation links to open the registration form and data table. The registration page is a front-end demo and does not send account data to a server.
